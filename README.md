# AI_Prompt

AI 관련 글(블로그, SNS, 뉴스레터, 커뮤니티 게시물 등)에 소개된 프롬프트를 **직접 AI 모델에 넣어 따라 만들어 보고**, 그 결과를 **프롬프트 원문, 사용한 모델과 함께** 기록하는 저장소입니다.

## 이 저장소를 만든 이유

AI 글에는 "이 프롬프트 하나로 이런 걸 만들었다"는 데모가 자주 나옵니다. 그런데 막상 따라 해 보려고 하면 이런 정보가 빠져 있는 경우가 많습니다.

- **어떤 모델로** 만든 결과인지 (같은 이름의 모델이라도 버전마다 결과가 다릅니다)
- 한 번에 나온 결과인지, **여러 번 다듬은** 결과인지
- 프롬프트의 **어느 부분이** 결과를 좌우했는지

그래서 여기서는 같은 프롬프트를 직접 돌려 보고, 아래 세 가지를 한 폴더에 묶어 남깁니다.

1. **프롬프트 원문**: 글에서 본 그대로
2. **결과물**: 모델이 실제로 만들어 낸 파일
3. **제작 정보**: 사용한 모델(이름과 정확한 모델 ID), 도구, 날짜, 제작 과정 메모

이렇게 쌓아 두면 나중에 **다른 모델로 같은 프롬프트를 다시 돌려 비교**하거나, 프롬프트를 어떻게 쓰면 결과가 좋아지는지 감을 잡는 데 쓸 수 있습니다.

## 저장소 구조

작품(프롬프트) 하나당 폴더 하나를 쓰고, 폴더 이름 앞에 만든 순서대로 번호를 붙입니다(`01-`, `02-` …). 두 자리로 맞추는 이유는 10번째 항목부터도 목록이 순서대로 정렬되게 하기 위해서입니다.

```
AI_Prompt/
├── README.md
└── <번호>-<작품-이름>/   # 예: 01-citrus-jelly
    ├── <결과물>      # 예: citrus-jelly.html
    └── prompt.md     # 프롬프트 원문 + 사용 모델 + 제작일 + 메모
```

### Citrus Jelly 쉽게 설명하면

**무엇인가요?**
브라우저에서 바로 열리는 HTML 파일 하나입니다. 화면 속 반달 모양 오렌지 젤리를 마우스나 손가락으로 잡아당기면 말랑하게 늘어나고, 놓으면 출렁이며 제자리로 돌아옵니다. 외부 라이브러리 없이 파일 하나에 모든 코드가 들어 있습니다.

**어떻게 움직이나요?**
- 젤리 속을 눈에 보이지 않는 작은 삼각뿔(사면체) 1,152개로 잘게 나눕니다.
- 각 조각은 "원래 모양으로 돌아가려는 성질"과 "부피를 유지하려는 성질"을 가집니다. 이 규칙을 1초에 1,200번씩 풀어서 젤리의 움직임을 계산합니다(XPBD라는 물리 시뮬레이션 기법).
- 눈에 보이는 매끈한 표면은 이 뼈대 위에 씌운 껍데기라서, 뼈대가 움직이면 함께 따라 움직입니다.

**어떻게 그려지나요?**
- 사진 스튜디오처럼 하얀 배경지, 위쪽 소프트박스, 뒤쪽 스트립 조명, 앞쪽 반사판을 코드로 만들어 배치했습니다.
- 빛이 젤리를 통과하면서 두꺼운 곳은 진하게, 얇은 곳은 연하게 물듭니다. 젤리 뒤의 배경이 휘어 보이는 굴절과, 젤리 색으로 물든 부드러운 그림자도 표현합니다.
- 젤리 안에는 과육 사이의 하얀 막, 씨앗, 작은 공기 방울, 설탕 결정 같은 반짝임이 들어 있습니다.

**어떻게 보나요?**
- **WebGPU를 지원하는 브라우저**가 필요합니다(최신 Chrome, Edge, Safari 등). 지원하지 않으면 "This slice needs WebGPU." 안내 화면이 나옵니다.
- GitHub에서 파일을 열면 코드만 보입니다. 파일을 내려받은 뒤 브라우저로 여세요.

**조작법**

| 조작 | 동작 |
| --- | --- |
| 드래그 (마우스·터치) | 젤리를 잡아 늘리기, 놓으면 출렁이며 복귀 |
| Orange / Blood Orange / Lemon | 품종(과육·내피·껍질 색) 바꾸기 |
| Firmness | 단단함 조절 |
| Internal damping | 출렁임이 잦아드는 속도 조절 |
| Give it a nudge (`N`) | 살짝 튕기며 비틀기 |
| Reset (`R`) | 처음 상태로 |
| Pause (`Space`) | 일시정지 / 재개 |
| Mesh overlay (`M`) | 내부 계산용 뼈대(사면체) 보기 |

### Tidepool Jelly 쉽게 설명하면

**무엇인가요?**
해안선 한 조각을 케이크처럼 잘라 낸 3D 디오라마입니다. 모래, 바위, 물, 생물이 모두 말랑한 젤리로 되어 있고, 잘린 옆면에는 지층이 젤리 디저트처럼 층층이 보입니다. 마우스로 돌려 보고 확대할 수 있습니다.

**무엇이 움직이나요?**
- **물:** 파도가 해변으로 밀려오고, 물을 클릭하거나 드래그하면 잔물결이 퍼졌다가 잦아듭니다. 물 아래에는 햇빛이 만든 일렁이는 빛 무늬(커스틱)가 비칩니다.
- **조수:** 바닷물이 차오르면 바위 웅덩이가 잠기고, 빠지면 웅덩이에 물이 갇힌 채 남아 천천히 줄어듭니다.
- **생물:** 게는 바위를 옆걸음으로 돌고, 해면은 물결에 흔들리고, 달팽이는 천천히 기어가고, 물고기는 무리 지어 헤엄칩니다. 불가사리, 조개, 새우도 각자 다르게 움직입니다.
- **생물을 누르면:** 카메라가 그 생물로 다가가 이름 카드가 뜨고, 한 번 더 누르면 말랑하게 찌그러졌다가 원래 모양으로 돌아옵니다.
- **밤:** 조명이 달빛으로 바뀌고, 물결이 이는 곳과 선택한 생물이 은은하게 빛납니다.

**어떻게 보나요?**
- **WebGL 2를 지원하는 브라우저**와 인터넷 연결이 필요합니다. 3D 엔진(Three.js)과 글꼴을 인터넷에서 불러옵니다.
- GitHub에서 파일을 열면 코드만 보입니다. 파일을 내려받은 뒤 브라우저로 여세요.

**조작법**

| 조작 | 동작 |
| --- | --- |
| 물 위에서 클릭·드래그 | 잔물결 만들기 |
| 그 밖의 곳에서 드래그 | 시점 돌리기 |
| 스크롤 (두 손가락) | 확대·축소 |
| 생물 누르기 | 생물로 이동하고 카드 보기, 다시 누르면 찌르기 |
| Tide · Auto cycle | 조수 높이 직접 조절 / 자동 밀물·썰물 |
| Waves · Clarity | 파도 세기 / 물의 맑기 |
| Softness | 젤리의 말랑함 |
| Day · Night | 낮·밤 조명 |
| 종 이름 버튼 | 종별로 보이기·숨기기 |
| Pause (`Space`) · Reset · Randomize | 일시정지 / 처음 상태로 / 새 지형과 생태계 만들기 |

### Fashion Contact Sheet 쉽게 설명하면

**무엇인가요?**
인물 사진 한 장을 주고, 같은 사람을 패션 화보처럼 아홉 가지 각도(바닥에서 올려다보기, 초근접, 드론 시점, 옆모습 등)로 찍은 듯한 3×3 컨택트 시트를 만들게 한 결과입니다. 앞의 두 항목과 달리 코드가 아니라 **이미지 생성 모델이 만든 그림 한 장**입니다.

**어떻게 만들었나요?**
- OpenAI의 GPT 이미지 생성을 Codex CLI의 내장 도구로 호출했습니다. Claude Code가 프롬프트 전달, 결과 점검, 기록을 맡았습니다.
- 원문 그대로 넣은 첫 시도는 OpenAI 안전 시스템에서 차단됐고, 하의를 반바지에서 청바지로 바꾼 두 번째 시도가 성공했습니다. 바꾼 문장과 조건별로 맞은 것·다른 것은 `prompt.md`에 정리했습니다.
- 같은 프롬프트를 **9컷으로 나눠 한 장씩 생성하고, 그리드·테두리·라벨은 코드(`compose.py`)로 합친 판**도 만들었습니다. 패널 비율과 라벨 철자가 정확해지는 대신 생성을 9번 써야 하고, "프롬프트 한 번으로 나온 결과"는 아니게 됩니다. 두 판의 차이는 `prompt.md`의 비교표에 있습니다.
- 참조 사진은 개인 사진이라 저장소에 올리지 않았습니다.

**어떻게 보나요?**
한 번에 생성한 판은 `contact-sheet.png`, 9컷을 합성한 판은 `contact-sheet-9shot.png`입니다. 컷별 원본은 `panels/` 폴더에 있습니다(GitHub에서도 바로 보입니다).

### One-Take Launch Film 쉽게 설명하면

**무엇인가요?**
애플 키노트의 제품 소개 영상처럼 만든 27초짜리 정사각형 영상입니다. 장면이 바뀔 때 컷이나 페이드를 쓰지 않고, 화면 속 물체가 모양을 바꾸며 다음 장면으로 이어집니다. 가상의 사진 인화 앱 **Hang.** 이 주인공이고, 사진 한 장이 휴대폰과 맥, 웹 페이지를 지나 실제 벽에 걸린 액자가 되는 과정을 보여 줍니다.

**어떻게 만들었나요?**
- 영상 전체가 HTML 파일 하나(`launch-film.html`)입니다. `seek(t)`라는 함수에 시각을 넣으면 그 순간의 화면이 계산되고, 이 함수를 1초에 240번 불러 화면을 찍은 뒤 4장씩 섞어 60fps 영상으로 만들었습니다(`tools/render.mjs`).
- 모든 움직임은 스프링 공식으로 계산하고, 유리처럼 보이는 부분(iOS 26의 리퀴드 글래스 느낌)은 SVG 필터로 뒤 배경을 휘게 만들었습니다.
- 120 BPM에 맞춰 54박 동안 박마다 무언가가 일어납니다. 음악의 드롭에 화면이 확대되고, 잔잔한 브레이크다운에 벽 장면이 나오고, 박자가 돌아오는 순간 로고가 다시 나타납니다.
- 재료는 직접 고르거나 만들었습니다.
  - 사진 12장: GPT 이미지 생성(Codex CLI)
  - 음악: Mixkit의 *Winter Breeze*(Arulo)를 마디 단위로 잘라 27초로 이어 붙임(생성한 음악이 아님)
  - 효과음 27종: Mixkit
  - 벽 영상: Pexels
- 음원, 효과음, 벽 영상, 사진 원본은 라이선스상 원본 파일을 다시 배포할 수 없거나 용량이 커서 저장소에 올리지 않았습니다. 출처와 ID는 `prompt.md`에 적었습니다.

**어떻게 보나요?**
`film.mp4`가 완성 영상입니다(GitHub에서 내려받아 재생). 장면 순서는 `beatmap.md`, 대표 장면 4장은 `stills/`에 있습니다. HTML은 `assets/` 폴더의 재료가 있어야 움직이므로, 저장소만 받아서는 열리지 않습니다.

## 새 항목 추가하는 방법

`main`에 직접 올리지 않고, 브랜치를 만들어 **PR(Pull Request)로** 올립니다.

1. 브랜치 만들기: `git switch -c add/<작품-이름>`
2. 다음 번호를 붙여 `<번호>-<작품-이름>/` 폴더를 만들고(예: `03-...`), 결과물과 `prompt.md`를 넣기 (아래 템플릿 참고)
3. 이 README의 **기록 목록** 표에 한 줄 추가
4. 커밋하고 브랜치를 푸시한 뒤 PR 만들기
5. PR에서 결과를 확인하고 `main`에 병합

### `prompt.md` 템플릿

```markdown
# <작품 제목>

| 항목 | 내용 |
| --- | --- |
| 결과물 | [`파일이름`](./파일이름) |
| 제작 모델 | 모델 이름 (`정확한-모델-ID`) |
| 도구 | 예: Claude Code, ChatGPT, Cursor … |
| 제작일 | YYYY-MM-DD |
| 프롬프트 출처 | 프롬프트를 본 글의 링크 |

## 프롬프트

(글에 나온 원문 그대로. 번역하거나 고쳤다면 그 사실을 적기)

## 제작 메모

- 원문과 다르게 해석하거나 정한 부분
- 한 번에 나온 결과인지, 몇 번 다듬었는지
- 직접 확인한 것과 확인하지 못한 것
```

## 기록 원칙

- **프롬프트는 원문 그대로** 옮깁니다. 번역하거나 수정했다면 그 사실을 함께 적습니다.
- **모델은 정확한 ID까지** 적습니다. 같은 이름이라도 버전에 따라 결과가 크게 달라집니다.
- **출처를 남깁니다.** 다른 사람이 공개한 프롬프트이므로 원문 글 링크를 기록합니다.
- **과정을 숨기지 않습니다.** 결과를 다듬기 위해 추가로 요청했거나 고친 부분이 있으면 메모에 남깁니다. 그래야 "프롬프트 하나로 된 것"과 "다듬어서 된 것"을 구분할 수 있습니다.
- 모든 결과물은 **AI가 생성한 것**이며, 원 글에 실린 결과와 다를 수 있습니다.
